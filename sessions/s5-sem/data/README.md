# 학습 말뭉치

`corpus.txt`는 S1·S2 예제 코드를 경로 순서대로 결합한 뒤 네 번 반복한 학습 데이터입니다. 글자 모델의 학습, 체크포인트 저장 및 텍스트 생성에 사용합니다.

반복된 데이터는 학습 프로그램의 검증 창 16개(각 256토큰)에 필요한 길이를 확보합니다. 학습 프로그램은 전체 데이터의 뒤쪽 10%를 검증에 사용합니다.

개발자 세션의 시연 데이터는 고정된 표준 라이브러리 소스이며, 이 저장소의 기본 데이터와 구성이 다릅니다. 따라서 학습 손실과 생성 결과는 시연 결과와 차이가 있습니다.

이 말뭉치는 저장소의 예제 코드와 동일한 MIT 라이선스로 제공됩니다.
