## 재실행 기록

최초 실행은 51개 통과, 1개 실패였습니다. 메모 편집 앱의 서명 단계에서 macOS 코드 서명 도구가 내부 오류를 반환했습니다. 해당 프로젝트의 별도 재빌드와 엄격한 코드 서명 검사가 통과했고, 전체 52개 항목을 다시 실행하여 모두 통과했습니다. 최초 오류의 원인은 확정하지 않았습니다. [서명 재검증 기록](archive/signing-retry.json)과 [최초 실행 기록](archive/sync-initial-verification-results.json)을 보존합니다.

## 검증 실행

검증 도구는 HMJE로 작성되어 있으며 HmjeFiles, HmjeProcess 및 기반 라이브러리를 사용합니다. 저장소 루트에서 실행합니다.

```sh
./tools/verify.sh
./tools/verify.sh --session s1
./tools/verify.sh --compile-only
```

`verify.sh`는 검증 도구를 빌드한 뒤 실행합니다. `HMJEC` 환경 변수로 컴파일러를 지정합니다. 결과 파일과 로그는 `build/verification/`에 저장됩니다.

Windows에서는 `tools/verify.ps1`을 사용합니다.

```powershell
.\tools\verify.ps1 --session s1
```

컴파일과 실행의 기본 제한 시간은 각각 600초와 120초입니다. `--compile-timeout`과 `--run-timeout`으로 1..3600초 범위에서 지정할 수 있습니다. `--output`은 결과 경로, `--manifest`는 검증 목록 경로를 지정합니다. 오류 진단 항목은 `diagnostic_contains`에 지정된 문자열을 모두 확인합니다.

진단 불일치와 제한 시간 초과 시 실패 처리, 잘못된 옵션·누락된 검증 목록·컴파일러 경로의 오류 종료도 확인했습니다.

정상 단일 파일 예제는 빌드 후 제공된 입력으로 실행합니다. 오류 예제는 컴파일 실패와 예상 진단을 확인합니다. 예약 서비스 테스트는 정상 종료와 `실패 0개` 출력을 확인합니다.

## 검증 범위

UI 프로젝트는 macOS 앱 빌드를 검증합니다. macOS 외 호스트에서는 해당 항목을 건너뜁니다. S5의 일괄 검증은 학습·이어쓰기·젬마 실행 파일의 빌드를 포함하며, CPU 학습과 텍스트 생성은 별도로 실행했습니다.

다음 항목은 검증 범위에 포함되지 않습니다.

- Windows PowerShell 스크립트 및 Windows·Linux 실행
- UI 입력, 미리보기 및 화면 표시 동작
- iOS 시뮬레이터 실행 및 기기 서명
- Metal 학습, 8000걸음 학습 및 외부 GGUF 모델 추론
- 배포 패키지 설치

POSIX 스크립트 문법, 문서의 상대 링크 및 예제 소스 83개 파일의 SHA-256도 확인했습니다. 결과는 위에 명시된 툴체인과 SDK 구성을 기준으로 합니다.
